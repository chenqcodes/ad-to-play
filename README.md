# Ad to Play

广告里那种简单快乐，打开就能玩。两款原创小游戏，静态网页，无依赖、无账户、无广告、无内购、无追踪。

## 01 · 霓虹小队

入口 `/`。手机竖屏，单指左右拖动，全队自动射击；电脑可用方向键 / A D，空格或 Esc 暂停。

- **三条约一分钟的路线**：集结大道（人数成长）、火力试炼（武器取舍）、守卫封锁（闪避生存）。全部直接可选，不需要刷关解锁。
- **真的能打的数值门**：对准带靶标的数字门持续开火，负数可打成增援。门面显示当前人数、成长进度和上限；过门只结算一次，可以从中央绕开。
- **三种换装**：散射枪是三发扇形，穿透枪最多贯穿三名敌人，爆破炮是慢速有界范围伤害。每名活着的队员实际发射，不用虚假的“战力”替代子弹。
- **公平的终点 Boss**：红色危险区先标位置、再倒数攻击；低血量加快节奏。失败显示具体原因，一键重来；通关可直接下一关。
- **轻量反馈**：命中亮度、爆裂、换枪外形与合成音效。声音默认关闭；震动可选且默认关闭；支持系统与手动减少动态。
- **本机纪录**：最快通关、最远进度、峰值人数与当局火力路线。只存当前浏览器，不上传，不改变游戏难度。

### 射击碰撞规则

子弹按路径先命中最近目标。数字门会吸收子弹，即使已到成长上限，穿透弹也不能穿过门；换枪门和连射门不挡子弹。散射的三颗弹按总量折算打门贡献，爆炸不会隔空给其他门加值。打门区和密集战斗区错开，且不存在强制负数门。

## 02 · 拉针救援：熔岩遗迹

入口 `/games/pin-rescue/`。十关原创拉针谜题，先用水冷却熔岩，再把探险家和全部宝石送到出口。

- 点击有编号的金色拉针，沿清晰通道移动内容物
- 免费、无限撤销与重来；提示根据当前局面求解
- 关卡逐步介绍机关；进度仅保存于当前浏览器
- 原创 SVG 探险家、宝石、水和熔岩，无外部图片

## 本地运行

需要 Node.js 20+，不需要 `npm install`。

```sh
npm run dev         # http://localhost:4173
npm run check       # 语法 + 全部测试 + 静态构建
npm run build       # 输出 dist/
npm run preview     # 预览 dist/
```

Cloudflare Pages：构建命令 `npm run build`，输出目录 `dist`。无环境变量、服务端、数据库或 API 密钥。GitHub 仓库 `chenqcodes/ad-to-play`；Pages 项目 `game`。具体发布检查见 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 工程约束

射击逻辑以 120 Hz 固定步长推进，与渲染帧率分离。DPR 最大 2；42 人、480 子弹、96 敌人对象池，特效共享 280 个预算（减少动态为 80）。失焦、切后台自动暂停，返回后需主动继续。Pointer capture 管理单指拖动；不阻止画布外的正常页面滚动。

拉针规则为纯函数，所有关卡均求解验证；覆盖所有拉针排列、错误顺序、撤销及存储失败。浏览器禁用或写满本地存储时，仍可正常玩本次会话。

`test/` 为射击逻辑、帧率、渲染和 DOM 集成测试；`games/pin-rescue/test/` 为谜题规则和 UI 测试。模拟 DOM / Canvas 测试不替代 Safari/Android 真机测试；验收范围见 [VERIFICATION.md](VERIFICATION.md)。

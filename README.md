# Ad to Play · 霓虹小队

广告里的那一关，这次真的能玩。

Ad to Play 是一个可以逐步增加小游戏的独立静态站。当前只有第一款原创试玩游戏「霓虹小队」：手机竖屏，单指左右拖动，队伍自动射击，通过人数门招募队友，躲开敌群和预警，击败终点 Boss。

**纯前端、零运行依赖、无账户、无后端、无广告、无内购、无第三方追踪。** 不需要安装，也不依赖局外养成。

## 本地运行

需要 Node.js 20 或更高版本。不需要安装 npm 依赖。

```sh
npm run dev
# http://localhost:4173
```

## 检查与构建

```sh
npm test       # Node 内置测试运行器
npm run check  # 语法检查 + 全部测试 + 生产构建
npm run build  # 生成 dist/
npm run preview
```

`dist/` 可直接交给任意静态托管。源码使用原生 ES modules，不能直接双击 index.html 作为正式测试方式，请通过 HTTP(S) 打开。

## 操作

- 手机：点「开始这一关」，按住游戏画面左右拖动；松手后小队停留在当前位置并继续射击。
- 电脑：鼠标拖动，或 ← / →、A / D 移动。
- 空格、Escape 或右上角暂停键：暂停 / 继续。
- 点击右上角音符按钮开启声音；默认静音，且不会在开始游戏前创建音频上下文。
- 切到后台或浏览器窗口失焦时自动暂停，回来后手动继续。
- 失败后点击「立即再来」，无需等待、看广告或消耗次数。

## 第一关规则

- 初始 3 人，上限 36 人；每个存活成员每轮实际发射一发独立子弹。
- 六组人数门，正门与负门左右交替；按小队中心位置选门，同一排门只结算一次。
- 所有负门都可以避开，每排都有正门，中间也保留可绕过的空隙。
- 敌人接触小队扣除 2 人，每个敌人最多造成一次接触伤害。
- 第 45 秒出现 Boss。红色区域预警 1.25 秒后攻击，命中扣 6 人，可以移动躲开。
- Boss 被击败即通关；人数归零或到 62 秒仍未击败 Boss 则本局结束。
- 自动化参考路线用时约 55.47 秒，没有购买、升级或局外数值加成。

## 实现

```text
index.html          独立站入口、操作提示、游戏 HUD 和结果层
styles.css          桌面 / 手机响应式页面
src/game.js         与 DOM 无关的确定性游戏逻辑
src/render.js       Canvas 2D 伪 3D、原创角色、光效、粒子
src/main.js         输入、状态层、音效、动画帧与后台暂停
public/favicon.svg  原创图标
public/_headers     Cloudflare Pages 安全响应头
scripts/build.mjs   零依赖静态构建
scripts/serve.mjs   本地 HTTP 预览
test/               游戏逻辑回归测试
```

### 性能边界

- 固定 120 Hz 逻辑步长，渲染用 requestAnimationFrame；长帧最多补算 0.25 秒。
- DPR 上限 2，ResizeObserver 跟随画布尺寸；不以每帧移动固定像素驱动游戏。
- 子弹对象池 480、敌人对象池 96、粒子对象池 280（减少动态效果模式 80）。
- 小队人数上限 36，参考完整通关峰值为 216 发子弹、18 个敌人。
- Pointer capture、单活动指针、touch-action: none，拖出画面仍能释放控制。
- 支持 prefers-reduced-motion，关闭震屏并减少粒子。
- 没有网络请求、Cookies、localStorage、分析 SDK、远程字体或远程素材。

### 可测试性

`src/game.js` 可直接在 Node 中模拟完整一局。测试涵盖：正负门、同排防重复、队伍上限、人数与射弹数一致、子弹扫掠碰撞、避让、敌人接触、Boss 预警与胜利、超时、暂停、重开、对象池、30/60/120/144Hz 一致性。

本地加 `?qa=1` 可启用 `window.__NEON_QA__` 状态查看接口，供开发验收；普通访问不会暴露此全局接口，也不会发送或存储任何数据。此接口不是账户或安全边界，游戏完全在访问者本地运行。

## 部署到 Cloudflare Pages

预定仓库：`chenqcodes/ad-to-play`，项目名：`game`，目标域名：`game.cqzzz.top`。

- 构建命令：`npm run build`
- 输出目录：`dist`
- 根目录：仓库根目录
- Node.js：20 或更高，建议 22 LTS
- 无环境变量、数据库、密钥或后端服务
- `public/_headers` 会被复制到输出目录，托管后需验证其实际响应头

域名绑定、DNS 和正式发布由仓库维护者单独执行。应用不依赖上述域名，预览环境同样可运行。

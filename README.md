# Ad to Play · 霓虹小队

广告里的那一关，这次真的能玩。

Ad to Play 是可以逐步增加小游戏的独立静态站。当前第一款原创游戏「霓虹小队」：手机竖屏，单指左右拖动，队伍自动射击，在招人和连射之间选择，躲过敌群与预警，击败终点守卫。

**纯前端、零依赖、无账户、无后端、无广告、无内购、无第三方追踪。** 不需要安装，也不依赖局外养成。

## 本地运行

需要 Node.js 20 或更高版本，不需要安装 npm 依赖。

```sh
npm run dev      # http://localhost:4173
npm test         # Node 内置测试运行器
npm run check    # 语法检查 + 全部测试 + 生产构建
npm run build    # 生成 dist/
npm run preview  # 预览 dist/
```

`dist/` 可交给静态托管。源码使用原生 ES modules，请通过 HTTP(S) 打开，不要直接双击 index.html。

## 操作

- 手机：点「开始这一关」，按住画面左右拖动；松手后保持位置并继续射击。
- 电脑：鼠标拖动，或 ← / →、A / D 移动。
- 空格、Escape 或右上角暂停键：暂停 / 继续。
- 默认静音，右上角音符按钮可开启声音。开始游戏之前不会创建音频上下文。
- 切到后台或窗口失焦时自动暂停，回来后手动继续。
- 失败后点「立即再来」，无需等待、广告或次数。

## 0.2：先让玩法更好玩

- **更早进入状态**：4 人出发，开场就有可击中的敌人；约 2.3 秒拿到第一个 +4 门。
- **成长有选择**：六排门中三排是「招人 / 全队连射」二选一。人数增加弹幕宽度和每轮弹量；连射让现有每个人更快开火。
- **挑战有起伏**：0–12 秒热身集结，12–28 秒火力升级，28–42 秒突破防线；中后段穿插重敌，Boss 前留出空档。
- **失误可以补救**：敌人接触后有 0.45 秒保护，避免一团怪在同一瞬间连续扣光队伍。红门仍按门上数值扣人。
- **终点更明确**：42 秒出现 Boss，半血后预警加快，HUD 显示血量与剩余秒数。60 秒未击败则结束。

### 精确规则

- 初始 4 人，上限 42 人。每位存活成员每轮发射一发真实独立子弹，基础间隔 0.28 秒。
- 蓝门连射最多两级，射速相对基础值为 ×1.35、×1.70。门上显示将获得的实际倍率；达到两级后，后续蓝门直接变成 +5 招人门。
- 所有门按小队中心位置选择；同一排只结算一次。每排至少有一个有益选项，中间保留绕过空隙。
- 普通敌人接触扣 2 人，重敌接触扣 4 人；每个敌人只结算一次接触。
- Boss 激光先标记玩家位置，普通预警 1.2 秒、半血后 1 秒，命中扣 8 人；提前离开标记区域即可避开。
- Boss 被击败即胜利；人数归零或 60 秒超时即失败。升级只在本局内有效，重开完整重置。

### 可重复的平衡验证

下表是固定输入策略的自动模拟，**不是人类玩家的胜率或难度承诺**。

| 策略 | 结果 | 用时 | 最终人数 / 连射级别 |
| --- | --- | --- | --- |
| 每次优先招人，主动躲激光 | 通关 | 51.767 秒 | 37 / 0 |
| 先招人再连射 | 通关 | 50.533 秒 | 26 / 2 |
| 优先连射 | 通关 | 51.242 秒 | 24 / 2 |
| 漏一门、跟枪慢 350ms、吃首轮激光 | 通关 | 57.925 秒 | 12 / 2 |
| 高失误路线 | 失败 | 11.417 秒 | 0 / 1 |
| 一直停在中央 | 失败 | 33.225 秒 | 0 / 0 |
| 全招人但不主动躲激光 | 通关 | 52.575 秒 | 21 / 0 |

策略定义见 `test/policies.mjs`，可复现和调整。目标是有多条可赢路线，做对选择和躲避会更快、更稳；并非每次失误都必须失败。

## 实现

```text
index.html          入口、操作提示、HUD 和结果层
styles.css          桌面 / 手机响应式页面
src/game.js         无 DOM 的确定性游戏逻辑与关卡数据
src/render.js       Canvas 2D 伪 3D、原创角色、光效、粒子
src/main.js         输入、状态层、音效、动画帧与后台暂停
public/favicon.svg  原创图标
public/_headers     Cloudflare Pages 安全响应头
scripts/build.mjs   零依赖静态构建
scripts/serve.mjs   本地 HTTP 预览
test/policies.mjs   完整对局的可重复输入策略
test/*.test.mjs     逻辑、模拟 DOM 输入与渲染规则回归测试
```

### 性能边界

- 固定 120 Hz 逻辑步长，requestAnimationFrame 渲染；长帧最多补算 0.25 秒。
- DPR 上限 2，ResizeObserver 跟随画布；移动、射击与伤害不依赖渲染帧率。
- 子弹池 480、敌人池 96、粒子池 280，减少动态效果模式下粒子池 80。
- 七条完整模拟路线最高 260 发在场子弹、17 个敌人。
- 42 人 / 连射 2 的持续射击压力测试峰值 420 发子弹，没有因池耗尽漏发。
- Pointer capture、单活动指针、touch-action: none；支持 prefers-reduced-motion。
- 没有第三方网络请求、Cookies、localStorage、分析 SDK、远程字体或远程素材。

### 可测试性

55 项自动测试覆盖门、招人、升级、实际射弹、碰撞、接触保护、Boss、胜败、暂停、重开、实体上限及输入集成。七条完整路线在 30/60/120/144Hz 渲染步进下，结果、实体峰值与事件时间线严格一致。

加 `?qa=1` 可启用 `window.__NEON_QA__` 状态查看接口。普通访问不暴露此全局接口；接口不发送或存储数据，也不是账户或安全边界。游戏完全在访问者本地运行。

## 部署

源码仓库：`chenqcodes/ad-to-play`。目标域名：`game.cqzzz.top`。现有初版预览：https://game-dx1.pages.dev/ 。

- 构建命令：`npm run build`
- 输出目录：`dist`
- 根目录：仓库根目录
- Node.js：20 或更高，建议 22 LTS
- 无环境变量、数据库、密钥或后端服务
- `public/_headers` 会复制到输出目录，托管后需检查实际响应头

应用不绑定域名。提交到已连接 Pages 的生产分支可能触发自动发布，更新前请先核对目标分支和预览计划。具体清单见 [DEPLOYMENT.md](./DEPLOYMENT.md)。
